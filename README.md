GrindX AI – Full-Stack GenAI Application

Overview:
GrindX AI is a production-style GenAI application that helps users work with documents, images, URLs and study/work content.

Key features:
- Document-aware AI chat
- OCR/image input
- URL analysis
- Summaries and key concepts
- Practice questions and mock tests
- Translation and audio support
- Authentication and usage controls
- Frontend + backend application flow

Architecture:
Frontend:
- User login
- File upload
- Chat interface
- URL input
- Response display

Backend:
- Authentication checks
- Usage controls
- Document/text processing
- AI prompt workflow
- Model/API integration
- Error handling

Security:
- Secrets are managed through environment variables
- API keys are not committed to GitHub
- Private user data is not exposed

Status:
This repository is private and used as a portfolio/technical demonstration project.
