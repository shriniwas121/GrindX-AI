# GrindX AI Frontend

This folder contains the frontend application for GrindX AI.

## Purpose

The frontend provides the user interface for the GrindX AI application, including:

- User login and navigation
- File upload interface
- AI chat interface
- URL input and analysis flow
- Prompt/action buttons
- Display of AI responses
- Academy and public information pages
- Privacy, terms and account-related pages

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS

## Role in the application

The frontend sends user actions to the backend API.  
The backend handles AI workflows such as document processing, OCR/image input, URL analysis, prompt handling, usage checks and model/API calls.

## Notes

Secrets, API keys and environment-specific configuration should not be committed to this repository.
